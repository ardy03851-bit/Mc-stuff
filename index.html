    Run it in Minecraft

    The preview above is a renderer that runs entirely in Safari. To boot the real Java client with your mod loaded, export the project and run:

    1. Unzip the projectCopy it to a computer with JDK 21 installed.
    2. Boot the client./gradlew runClient
    3. Or build the jar./gradlew build Drop build/libs/*.jar into your mods folder.
    Needs Gradle + a Mojang account to launch.
